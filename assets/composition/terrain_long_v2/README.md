# Terreno novo — substituição do cenário rejeitado

Gerado com a ferramenta integrada image_gen em 2 de outubro de 2026. Referências de estilo: assets/houses/houses_01.png e assets/composition/castle.png. O terreno anterior não foi usado como referência, recortado, repetido ou ampliado nesta montagem.

Arquivos finais: west.png, central.png, east.png. Cada resultado nativo tem 2172 × 724 pixels, embora o pedido de geração solicitasse 3072 × 1024. Não houve redimensionamento para simular essa resolução. O Godot usa escala 1:1, com 128 pixels de sobreposição entre trechos: extensão final de 6260 unidades. Originais preservados no diretório de imagens geradas.
